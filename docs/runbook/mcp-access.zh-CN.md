# 后台 MCP 接入

登录后台后，在导航中选择 **MCP 接入**（也可直接访问 `/?mcp`）。页面展示当前服务的 `/api/mcp` 地址并支持复制；地址使用后台当前配置的 API 服务地址。

## 创建专用令牌

默认仅允许读取笔记，且仅限 MCP 协议。选择需要授权的笔记库后创建令牌；空选不会自动授予所有库权限。若选择“允许所有笔记库”，也包括将来新增的库。根据客户端用途，可额外允许笔记写入和附件访问。默认有效期为 30 天。

令牌仅在当前页面内存中保存，复制后请保存到客户端的认证设置。离开页面或刷新后不能再次显示原始令牌。可从原有令牌管理入口撤销或轮换。

## 配置客户端

远程传输使用 Streamable HTTP，服务地址为 `https://你的域名/api/mcp`。认证请求头为 `Authorization: Bearer <MCP_TOKEN>`。页面提供配置示例；具体 JSON 字段请以客户端支持的格式为准。仅支持 OAuth 登录、不能配置 Bearer 请求头的客户端可能需要额外适配。

## 测试连接

使用刚创建的令牌，或粘贴已有令牌，点击“测试连接”。页面执行 MCP 初始化与工具列表读取，显示服务器名称、协议版本及工具名称。测试不会调用写入工具。令牌、服务器响应正文不会写入日志或配置示例。

HTTP 错误通常表示令牌失效、未授权 MCP 或服务路径错误；网络错误可检查 HTTPS、服务连通性及允许的跨域来源。独立域名的后台须在服务端允许的 Origin 中配置其域名，服务端允许并暴露 MCP 会话头。
